Arquitectura clave

Modelos de servicio en la nube

  • IaaS

    Infraestructura como Servicio

    Provee servidores virtuales, redes y almacenamiento bajo demanda sin necesidad de adquirir ni mantener hardware físico propio.

  • PaaS

    Plataforma como Servicio

    Ofrece entornos administrados para desarrollar, probar y desplegar aplicaciones enfocándose únicamente en el código y los datos.

  • SaaS

    Software como Servicio

    Entrega aplicaciones listas para usar desde el navegador, como correo electrónico, almacenamiento colaborativo y plataformas de streaming.
